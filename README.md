# Penguin 🐧

A cute penguin illustration built using **HTML and CSS** as part of the FreeCodeCamp Responsive Web Design curriculum.

## Features

* Penguin illustration created using HTML and CSS
* Mountain and sky background
* CSS gradients for the background and penguin
* Animated waving arm
* Click interaction to enlarge the penguin
* Simple CSS-based shapes and positioning
* Responsive viewport setup

## Technologies Used

* HTML5
* CSS3
* CSS Variables
* CSS Gradients
* CSS Animations
* CSS Transforms
* CSS Positioning

## Project Structure

```text
Penguin/
├── index.html
├── styles.css
└── README.md
```

## What I Learned

In this project, I practiced building a character using HTML elements and CSS instead of images. I also practiced CSS positioning, gradients, pseudo-elements, transforms, animations, and CSS variables.
